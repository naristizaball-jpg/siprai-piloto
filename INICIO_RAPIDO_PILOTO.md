# SIPRAI 2.6 — Inicio rápido de piloto

## 1. Ejecutar localmente
Windows: `run_windows.bat`

Abrir:
`http://127.0.0.1:8000`

## 2. Crear contexto de un proyecto
En la pantalla principal registre:
- título
- etapa
- revista objetivo (si existe)
- pregunta
- objetivo
- método provisional

## 3. Consultar al Profesor SIPRAI
Cada consulta realiza:
Router 00 → controles → recuperación documental → plantilla → respuesta → traza.

## 4. Revisar la evidencia
La interfaz muestra referencias internas `[Dxx p.yy]`.

## 5. Modo IA
Por defecto: `local`.
Para conectar un modelo externo compatible, complete `.env` a partir de `.env.example`.

## 6. Regla de piloto
No use todavía datos personales sensibles reales ni decisiones de alto impacto hasta que la institución revise seguridad, privacidad y autenticación de producción.
