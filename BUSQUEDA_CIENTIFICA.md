# Búsqueda Científica

## OpenAlex
Se usa para exploración de metadatos:
- título
- autores
- año
- revista/fuente
- DOI
- conteo de citas
- acceso abierto

Los resultados NO equivalen a una revisión sistemática ni garantizan pertinencia.

## Crossref
Se prepara un endpoint para verificación de DOI.

## Futuras integraciones
- Crossref enriquecido
- ORCID
- Unpaywall
- Zotero
- Scopus / Web of Science según acceso institucional

## Regla metodológica
La búsqueda automática complementa, pero no reemplaza:
- ecuación documentada
- criterios de inclusión/exclusión
- fecha de consulta
- registro de resultados
- revisión humana
