- [ ] secreto de sesión aleatorio y no compartido
- [ ] HTTPS activo
- [ ] disco persistente montado en `/data`
- [ ] cuenta inicial del profesor creada por variables secretas
- [ ] contraseña inicial cambiada tras el primer acceso
- [ ] prueba de acceso estudiante A ≠ proyecto estudiante B
- [ ] prueba de exportación JSON
- [ ] prueba de backup
- [ ] carga de archivo válida e inválida
- [ ] prueba de T02 vacío sin evidencia
- [ ] prueba de conclusiones sin resultados
- [ ] prueba de agente IA con memoria
- [ ] política del piloto explicada a estudiantes
- [ ] no cargar datos sensibles reales en la primera cohorte
